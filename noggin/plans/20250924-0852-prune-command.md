# Prune Command Implementation Plan

## Objective
Implement a `prune` command for the 3pio CLI that cleans up old test runs and temporary files, keeping only the most recent run for reference.

## Success Criteria
- [x] `3pio prune` command successfully removes all but the most recent run
- [x] Debug log file is cleared
- [x] Command provides feedback about what was deleted
- [x] Command handles edge cases (no runs, missing directories)
- [x] Tests verify the prune functionality

## Tasks

### 1. Command Implementation
- [x] Add prune command to CLI argument parser in `cmd/3pio/main.go`
- [x] Create new prune package at `internal/prune/prune.go` with core logic
- [x] Implement function to identify and sort runs by timestamp
- [x] Implement deletion of old runs (keeping most recent)
- [x] Implement clearing of debug.log file

### 2. Core Functionality
- [x] Parse run directory names to extract timestamps
- [x] Sort runs by timestamp to identify most recent
- [x] Safely delete old run directories
- [x] Clear debug.log contents (keep file, empty contents)
- [x] Add dry-run mode (`--dry-run`) to preview what would be deleted
- [x] Add force mode (`--force`) to skip confirmation prompt

### 3. User Feedback
- [x] Display count of runs to be deleted
- [x] Confirm before deletion (unless --force flag)
- [x] Report successful deletion summary
- [x] Handle and report errors gracefully

### 4. Edge Cases
- [x] Handle missing .3pio directory
- [x] Handle no runs present
- [x] Handle permission errors
- [x] Handle corrupted/malformed run directory names
- [x] Ensure atomic operations where possible

### 5. Testing
- [x] Unit tests for prune logic
- [x] Integration test for full prune command
- [x] Test edge cases (no runs, single run, permission errors)
- [x] Test dry-run mode
- [x] Test force mode

## Verification Strategy
1. Run unit tests: `go test ./internal/prune`
2. Run integration test: `go test ./tests/integration_go -run TestPruneCommand`
3. Manual testing:
   - Create multiple test runs
   - Run `3pio prune --dry-run` to preview
   - Run `3pio prune` and verify only most recent remains
   - Verify debug.log is cleared

## Implementation Notes
- Use filepath.Walk for safe directory traversal
- Parse timestamps from directory names (format: YYYYMMDD_HHMMSS_*)
- Log to debug.log after clearing it
- Consider adding a `--keep N` flag in future to keep N most recent runs
